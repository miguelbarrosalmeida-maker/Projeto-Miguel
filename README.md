AgroForte - Simulador de Impacto Agro-Sustentável

Este projeto foi desenvolvido para o Concurso Agrinho 2026, dentro da categoria Programação, abordando o tema "Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente".

 Sobre o Projeto
O AgroForte é uma página interativa (Landing Page) que apresenta três pilares fundamentais da agricultura moderna. O grande destaque é o simulador dinâmico de práticas sustentáveis: conforme o usuário seleciona diferentes manejos (irrigação por gotejamento, rotação de culturas ou painéis solares), o sistema calcula em tempo real o impacto na produção e na preservação ambiental através de barras de progresso interativas.

Tecnologias e Declaração de Uso de IA
O código foi construído utilizando tecnologias web fundamentais: HTML5, CSS3 para o design responsivo e JavaScript (Vanilla) para a lógica dos seletores e cálculo de impacto.

Em conformidade com as boas práticas de integridade digital, declara-se que ferramentas de Inteligência Artificial (Generativa) foram utilizadas sob a supervisão do professor orientador exclusivamente para:
1. Refinamento de estilos e layouts no CSS.
2. Sugestões de estruturação lógica das funções de validação no JavaScript.
O conceito pedagógico, a escolha das variáveis agrícolas e o desenvolvimento textual foram totalmente concebidos pelo estudante.
